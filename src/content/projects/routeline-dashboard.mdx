## Context

Routeline's dispatchers track hundreds of deliveries at once. The old dashboard showed every metric at the same weight, so the one delayed truck that mattered looked like everything else.

## Approach

- Shadowed four dispatchers for a full shift each and listed every decision they made.
- Ranked alerts by what the dispatcher has to do next, not by how the data arrives.
- Built keyboard shortcuts for the ten most frequent actions, tested with timing sessions.

## Outcome

Dispatchers now see the few deliveries that need them first, and new staff learn the tool in a day. The colour and alert rules became tokens in a design system shared by the web and tablet apps.
